# OMNI-P1 model
The OMNI-P1 model weights and the original code showing how to use it. It is now integrated in the [MLatom package](https://github.com/dralgroup/mlatom), please use it in the future as this repository will not be updated in the future. See MLatom documentation for the tutorials on how to use OMNI-P1 for various applications such as geometry optimizations.

Paper:

- Yuxinxin Chen, Pavlo O. Dral. [One to Rule Them All: A Universal Interatomic Potential Learning across Quantum Chemical Levels](https://doi.org/10.1021/acs.jctc.5c00858). *J. Chem. Theory Comput.* **2025**, *21*, 8762–8772. DOI: 10.1021/acs.jctc.5c00858. Preprint on ChemRxiv: https://doi.org/10.26434/chemrxiv-2024-ng3ws (2024.09.18) | arXiv: https://arxiv.org/abs/2409.12015.
